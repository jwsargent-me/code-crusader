# Brand artwork

The Sentinel mascot and banner were generated with OpenAI image generation. The JPEG is a format export of the PNG banner.

- `sentinel-logo-light.png`: black artwork on white, 1254 × 1254; README light theme.
- `sentinel-logo-dark.png`: white artwork on black, 1254 × 1254; README dark theme.
- `code-crusader-social-preview.jpg`: 1774 × 887, under 1 MB; GitHub social-preview upload.
- `code-crusader-social-preview.png`: full-quality banner master.
